[树莓派] 2. 首次启动与连接网络

本笔记介绍的方法只适用于用网线直接连接树莓派和电脑，也许对使用WIFI连接有启发作用。

工具准备

  1. 一根网线
  2. 可以供电的type-C线
  3. 已经烧录好系统的SD卡
  4. micro-HDMI线，用于连接到显示器

硬件连接

  1. 将SD卡插入树莓派。
  2. 将Type-C供电接口插入树莓派
  3. 将网线插入树莓派以太网接口

硬件连接完成

首次启动

由于作者用的是一张大容量低速卡，首次启动需要等待的时间很长，建议第一次插卡后观察电源附近ACT小灯，如果疯狂闪光并且持续一段时间说明成功概率很大，需要耐心等待。
接下来，你可以进行电脑侧的网络配置，在配置完以后，就可以监测系统的运行状态。

电脑网络设置

  1. 打开电脑网络连接设置(输入win+R，然后输入ncpa.cpl).

  2. 找到现在电脑正在使用的网络（可上网的那个），右键，选择”属性“->”共享“

  3. 勾选“允许其他网络用户…”，并在下拉菜单中选择“以太网”。

    最后记得点击确定

监测运行状态

为了获取树莓派的IP，我们需要下载IP扫描软件 Advanced IP Scanner 扫描 192.168.137.1-254 网段。
Advanced IP Scanner可以在官网自行下载或者使用winget下载，
Advanced IP Scanner

进入界面以后，在图示位置改为192.168.137.1-254，从而扫描树莓派使用的网段，点击扫描后等待，可以看到有除了本机以外的另一台设备出现，记住这时出现的ip

打开电脑的命令行，使用ping命令对树莓派的状态进行监测

耐心观察，直到屏幕上出现第一条成功的 Reply from... (回复来自…)。这代表系统已准备就绪。看到回复后，按 Ctrl+C 停止 ping。

此时，可以连接显示器和键盘鼠标，进入系统桌面。

若显示如下所示，则说明树莓派成功连接了网络。

这一步顺利完成！我们的树莓派可以插着显示器和键鼠运行。
