零基础 Vibe Coding起步：用 OpenCode 桌面版连接 DeepSeek

写在前面：这篇教程会完成什么？

这篇文章会带你从一台没有开发环境的电脑开始，完成下面这条流程：

下载 OpenCode 桌面版 → 获取 DeepSeek API Key
→ 在 /model 中选择 DeepSeek → 打开项目文件夹

一、OpenCode 和 DeepSeek 分别做什么？

可以把这套组合理解成：

  • OpenCode 桌面版：工作台和执行者，负责读取、创建、修改本地项目文件；
  • DeepSeek API：背后的 AI 模型，负责理解需求、分析问题和生成代码。

OpenCode 是客户端，DeepSeek 是模型服务。两者连接时需要一把 DeepSeek API Key。

需要注意：DeepSeek 网页聊天和 DeepSeek 开放平台 API 是两套使用方式。本教程使用的是 DeepSeek 开放平台 API，费用从 API 余额中按实际用量扣除。

二、下载 OpenCode 桌面版

打开 OpenCode 官方下载页：
https://opencode.ai/download
在 OpenCode Desktop 区域找到 Windows (x64)，点击下载；
大多数 Windows 10/11 电脑都是 x64。如果你不确定，可以打开 Windows 的“设置 → 系统 → 系统信息”，查看“系统类型”。
如果是Mac电脑，选择对应的安装包下载即可

下载完成后，双击安装文件。如果 Windows 弹出安全确认窗口，请先核对文件来自 OpenCode 官方网站，再选择继续。

按照安装向导完成安装。通常保持默认设置即可，不需要手动选择 Node.js、Python 或其他开发组件。

安装完成后，从开始菜单打开 OpenCode。

三、注册 DeepSeek 开放平台并准备余额

打开 DeepSeek 开放平台：
https://platform.deepseek.com/
注册或登录账号，然后进入余额或充值页面。先充值一笔小额费用即可，新手不必一次充值很多。

模型价格会调整，建议随时查看 DeepSeek 官方价格页，不要把网上旧教程中的单价当作长期固定价格。

充值后确认账户中有可用余额。如果余额为 0，后续可能遇到 402 Insufficient Balance 错误。

进入 DeepSeek 开放平台的 API Keys 页面，点击创建新的 API Key。

十、常见问题

1. Windows 提示 OpenCode 无法启动

确认下载的是 Windows x64 版本，并尝试重新下载安装。OpenCode Desktop 在 Windows 上还依赖 Microsoft Edge WebView2 Runtime；大多数 Windows 10/11 已经自带，如果缺失，可从微软官方渠道安装后重试。

2. /model 没有反应

先输入 /models。如果仍然没有供应商或密钥配置界面，使用：


连接 DeepSeek 后，再返回模型选择器。

3. 提示 401 或 Authentication Fails

API Key 不正确或复制时带入了多余空格。重新复制；如果平台已经不再显示完整 Key，就删除旧 Key 并创建新的。

4. 提示 402 或 Insufficient Balance

DeepSeek API 余额不足。充值后回到 OpenCode 再试。

5. 列表中没有最新 DeepSeek 模型

退出 OpenCode，下载安装最新版桌面客户端。DeepSeek 当前建议使用兼容版本不低于 v1.14.24 的 OpenCode。

6. AI 修改了不该修改的文件

立即停止操作。确认当前打开的是独立项目文件夹，并从备份恢复。不要把整个桌面、文档总目录或重要资料目录作为 OpenCode 项目打开。

十一、安全与费用提醒

开始长期使用前，请养成下面几个习惯：

  • 不公开 API Key，截图前检查并完整打码；
  • 给不同工具创建不同的 Key，泄露后立即删除；
  • 定期查看 API 用量和余额；
  • 每次允许文件操作前先检查路径；
  • 每个项目使用独立文件夹；
  • 重要项目先备份，生成代码经过测试再使用；
  • 不把公司私有代码、客户数据或个人隐私发送给未经授权的模型服务。

    结语

    现在，你已经走完了完整流程： Vibe Coding 不是让 AI 随便写代码，而是把目标说清楚，观察实际结果，指出具体问题，再一轮轮接近想要的成品。

第一个项目不用很大。个人主页、倒计时、待办清单、课程表、番茄钟、简单记账页面，都很适合作为起点。能运行、能修改、能解决一个小问题，就是很好的第一步。
